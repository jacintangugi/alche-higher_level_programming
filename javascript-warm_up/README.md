# JavaScript - Warm Up

An introduction to basic JavaScript scripting with Node.js: variables, data
types, conditionals, loops, functions, recursion, objects, and modules.

## Requirements

- Ubuntu 20.04 LTS
- Node.js 14.x
- Semistandard style (Standard + semicolons)

## Files

- `0-javascript_is_amazing.js`: Prints a constant string
