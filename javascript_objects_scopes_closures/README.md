# JavaScript - Objects, Scopes and Closures

Covers ES6 classes, inheritance with `extends`/`super`, prototypes,
closures, and variable scope in JavaScript.

## Requirements

- Ubuntu 20.04 LTS
- Node.js 14.x
- Semistandard style (Standard + semicolons)
- `var` is not allowed anywhere

## Files

- `0-rectangle.js`: An empty Rectangle class
- `1-rectangle.js`: Rectangle with width/height attributes
- `2-rectangle.js`: Rectangle that stays empty if w/h invalid
- `3-rectangle.js`: Adds a print() method
- `4-rectangle.js`: Adds rotate() and double() methods
- `5-square.js`: Square class extending Rectangle
- `6-square.js`: Adds charPrint(c) method
- `7-occurrences.js`: Counts occurrences of an element in a list
- `8-esrever.js`: Reverses a list without using .reverse()
- `9-logme.js`: Logs call count and argument using a closure
- `10-converter.js`: Converts numbers between bases using a closure
