# JavaScript - Web Scraping

Scripts covering file I/O with the `fs` module, HTTP requests with the
`request` module, and working with JSON data from external APIs.

## Requirements

- Ubuntu 14.04 LTS
- Node.js 10.14.x
- Semistandard style (Standard + semicolons)
- `var` is not allowed anywhere
- `request` module (deprecated but required for this project)

## Files

- `0-readme.js`: Reads and prints a file's contents
- `1-writeme.js`: Writes a string to a file
- `2-statuscode.js`: Prints the HTTP status code of a GET request
- `3-starwars_title.js`: Prints a Star Wars movie title by episode ID
- `4-starwars_count.js`: Counts films featuring Wedge Antilles
- `5-request_store.js`: Fetches a webpage and saves it to a file
- `6-completed_tasks.js`: Counts completed tasks per user ID
